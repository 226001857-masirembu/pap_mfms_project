# MFMS Testing Plan

## Purpose

This document describes the tests that will be performed on the Municipal Financial Management System after all modules have been completed and integrated.

## Testing Areas

### 1. Main Menu
- Test each available menu option.
- Confirm that the correct function opens.
- Test invalid menu choices.

### 2. Employee Management
- Add an employee.
- Display employee records.
- Search for an employee.
- Test salary calculations.
- Test invalid employee input.

### 3. Budget Management
- Enter budget information.
- Enter expenditure information.
- Calculate remaining funds.
- Display budget information.
- Test invalid values.

### 4. Supplier Management
- Add a supplier.
- Display supplier records.
- Search for a supplier.
- Test invalid input.

### 5. Asset Management
- Add an asset.
- Display asset records.
- Search for an asset.
- Test invalid input.

### 6. Reports
- Generate/display employee information.
- Generate/display budget information.
- Generate/display supplier information.
- Generate/display asset information.

### 7. Integration
- Compile all modules together.
- Confirm that the modules work correctly with the main program.
- Test navigation between functions.
- Test invalid menu choices and input.

## Test Evidence

Screenshots and test results will be added after the complete system has been integrated and tested.
