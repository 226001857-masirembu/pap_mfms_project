**Project Description**
Our system aims to create a financial management system in C that displays and calculates employee, budget, supplier, and asset information, and generates detailed reports on these records.
**System Features**
- Employee management: add, display, and search employee records; calculate salary information.
- Budget management: record budgets and expenditure, calculate remaining funds, and display budget information. 
- Supplier management: add, display, and search supplier records.
- Asset management: add, display, and search asset records.
- Reports: show employee, budget, supplier, and asset information.
- Input validation: handle invalid menu choices and values where appropriate.
